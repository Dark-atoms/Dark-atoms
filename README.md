# Hi, I'm Subhrojyoti Mandal 👋

EEE graduate from **KUET** (Khulna, Bangladesh) working on **magnonics and micromagnetic simulation**: voltage-controlled magnetic anisotropy (VCMA), spin-wave logic devices, and GPU-accelerated simulation with MuMax3. I also build low-cost sensors and embedded systems.
